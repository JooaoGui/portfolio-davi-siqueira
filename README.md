## Como visualizar no VS Code

A maneira mais simples é instalar a extensão **Live Server**:

1. Abra esta pasta no Visual Studio Code.
2. Instale a extensão Live Server.
3. Abra `index.html`.
4. Clique em **Go Live** no canto inferior direito.

Também é possível usar o terminal:

```bash
python -m http.server 5500
```

Depois acesse `http://localhost:5500`.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos mantendo a estrutura de pastas.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve e aguarde a URL do GitHub Pages.
